# Финальное тестовое: обёртка над Keitaro

Это задание познакомит тебя с одной из систем, с которыми мы работаем каждый день. Срок — 5 дней.

Keitaro — рекламный трекер: по нему мы смотрим, насколько прибыльны объявления. Технически это конструктор ссылок: он перенаправляет пользователей по настроенным правилам и показывает статистику переходов.

## Задача из двух частей:

Создаватор кампаний. Принимает название кампании, гео-код страны и ID оффера в Keitaro. Создаёт кампанию с двумя потоками: первый ловит всех из указанной страны и отправляет на Google, второй отправляет на выбранный оффер. У кампании должны быть настроены домен, группа и источник — всё это есть в API.
Редактор существующей кампании. Умеет добавлять и удалять офферы. У нас такой редактор уже есть, видео с ним — в полном ТЗ. Интерфейс на твой вкус, главное — рабочие кнопки и верные цифры.
Стек: FastAPI + SQLAlchemy, фронт любой — хоть React, хоть HTML с jQuery. Cursor, Windsurf и другие ИИ-агенты категорически приветствуются.

## Как сдавать тестовое

Проект должен быть написан на FastApi + SQLAlchemy. Фронт - можно сделать любой, хоть React, хоть HTML-ки с кусками jquery.
ссылка на GitHub с понятным README по миграциям и запуску.
Сдавать работу в виде ссылки на гитхабе с понятным README для миграций и запуска. Использование агентов типа Cursor/Windsurf категорически приветствуется.

## Доступы в Keitaro:

Адрес: tlgk.host/admin
Логин: в .env
Пароль: в .env
Документация к API и ключ — в админке Keitaro.
Называй кампании с префиксом test*фамилия*, например test_ivanov_campaign1.
